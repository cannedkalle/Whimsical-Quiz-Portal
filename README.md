# Whimsical Quiz Portal

Kids quiz games at https://cannedkallequiz.vercel.app/

## Games

- **Balls in the Ballpark** (`/wild-guess`) — estimation game: which is more, bigger, longer? Categories: count, duration, frequency, length.
- **Before the Bulb** — invention history quiz
- **Tango Cards** — collectible card gallery
- **Marble Battles** — simulation game
- **Animal Outsider** — taxonomy game
- **Name Quest** — categorization game
- **Twin Terms** — two-hint word game
- **Spin Draw** — rotating-disc drawing toy

## Develop

```sh
npm install
npm run dev
```

## Test

```sh
npm run wild-guess:test
npm run test:wild-guess-images
npm run build
```

## Deploy

Vercel deploys from `main` automatically. Framework: Next.js.
